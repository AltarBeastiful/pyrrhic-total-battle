# Provenance

Factual Total Battle game statistics (unit health, strength, costs, bonus tables) as displayed by the game.
They were collected on 2026-09-12 by reading the data tables shipped in TotalStack's public client bundle and
are kept here only as research input. Before use in the app they are reshaped into our own format under
`src/data/tables/` and verified against in-game screens (see docs/PLAN.md §2.2–2.3). No TotalStack text,
help copy, UI or code is reused.
