Pyrrhic (this website)

Pyrrhic is a march calculator for Total Battle. The calculator runs in your browser and does not send your army data anywhere.

The “rclone” Google OAuth client

The Google Cloud project “rclone-sync” holds a single OAuth client used by the site owner to synchronise their own files between their own computer and their own Google Drive with the open-source tool rclone. It is a personal-use tool, not a service offered to the public.

What data is accessed

When the owner authorises the client, rclone obtains a token that lets it read and write files in the owner’s own Google Drive (scopes drive, docs and drive.metadata.readonly).

How data is used, stored and shared

  • Data travels only between Google Drive and the owner’s own computer.
  • The token is stored only in the owner’s local rclone configuration file. No server operated by the developer receives, stores or processes Google user data.
  • No data is sold, shared with third parties, used for advertising or read by humans.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the local rclone configuration to remove the token.
